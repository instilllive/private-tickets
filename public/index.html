How a night works

  1. The host creates an event and imports a guest list, or issues one named ticket.
  2. The guest opens their link. The page shows a QR code that changes every five seconds.
  3. A volunteer opens a door-staff link for that event. The scan works once. A photo from a few seconds ago does not.
  4. A transfer sits pending until the host approves it. Approval kills the old code and issues a new one.
